  • Appeared in: Dec 2024 (Q16a), May 2025 (Q15b), Dec 2025 (Q16b).

  • Appeared in: May 2025 (Q15a), May 2026 (Q16a), Model Paper (Q13a).

  • Appeared in: Dec 2024 (Q5), May 2025 (Q2), Dec 2025 (Q2), May 2026 (Q2).
  • Key rule: ** evaluates right-to-left ($2^{3^2} = 2^9 = 512$), while *, /, //, % evaluate left-to-right.

3. Comprehensive Module-Wise Breakdown

MODULE 1: Problem-Solving Strategies & Python Basics

3-Mark Questions (Part A)

  • Operator Precedence Output Questions:
    • Example 1: 2 * 3 ** 2 ** 2 → $3^{(2^2)} = 3^4 = 81 \implies 2 \times 81 = 162$.
    • Example 2: (50 - 5 * 6) // 4 → $(50 - 30) // 4 = 20 // 4 = 5$.
    • Example 3: (8 + 6 * 2 ** 3 ** 1) / 7 - 4 → $(8 + 6 \times 8) / 7 - 4 = 56 / 7 - 4 = 8.0 - 4 = 4.0$.
    • Example 4: not (10 < 5) or (5 == 5) → $\text{not False or True} = \text{True}$.
  • Strategy Identification:
    • Identify ill-defined problems (e.g., "Become successful", "Design a beautiful UI") vs. well-defined problems (e.g., "Find the GCD of 24 and 36", "Sort a list of numbers").
    • Strategy use-cases: Sudoku (Backtracking), Navigation / Trip planning (Heuristics or Means-Ends Analysis), Padlock unlocking (Brute Force / Trial & Error).
  • Python math Module Functions:
    • State any 3: math.sqrt(x), math.pow(x, y), math.gcd(a, b), math.ceil(x), math.floor(x).

6 to 9-Mark Questions (Part B)

  • [Priority 1 - Sure Shot] The 6 Problem-Solving Steps:
    • Must memorize the 6 formal headings:
      1. Understanding the problem (Inputs, outputs, constraints).
      2. Formulating a model (Mathematical equations, formulas).
      3. Developing an algorithm (Step-by-step logic).
      4. Writing the program (Python code).
      5. Testing the program (Test cases including boundary/edge values).
      6. Evaluating the solution (Time/space complexity and limitations).
    • Must-prepare problems: Area of circle ($A = \pi r^2$), Roots of quadratic equation ($x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$), Largest of three numbers.
  • [Priority 2] Means-Ends Analysis:
    • Define current state, goal state, identify differences, establish sub-goals/operators to reduce differences, evaluate progress.
  • [Priority 3] Short Python Scripts:
    • Reverse a 3-digit number without loops: rev = (n % 10)*100 + ((n // 10) % 10)*10 + (n // 100).
    • Calculate radius from area using math.sqrt(area / math.pi).
    • Convert total minutes to hours and minutes (hours = mins // 60, rem = mins % 60).

MODULE 3: Python Collections, Modularization & Recursion

3-Mark Questions (Part A)

  • String / List Slicing:
    • Slicing format: sequence[start:stop:step]
    • s[::-1] (reverses string/list), s[-3:] (last 3 elements), s[1:8:2] (alternate characters from index 1 to 7).
  • List vs. Tuple vs. String vs. Set:
    • List: Mutable, ordered, allows duplicates, uses [].
    • Tuple: Immutable, ordered, allows duplicates, uses ().
    • String: Immutable sequence of characters, uses "" or ''.
    • Set: Mutable, unordered, unique elements only, uses {}.
  • Recursion Basics:
    • What is circularity? (Infinite recursion caused by missing base case or recursive step not moving towards the base case, leading to stack overflow).
    • Functions with multiple return values in Python: return as a tuple (return a, b).

5 to 6-Mark Questions (Part B)

  • [Priority 1 - Sure Shot] Recursion with Call Stack Tracing:
    • Recursive multiplication of two positive numbers $a \times b$: $$\text{multiply}(a, b) = \begin{cases} 0 & \text{if } b = 0 \\ a + \text{multiply}(a, b - 1) & \text{otherwise} \end{cases}$$ Must know how to sketch stack push/pop frames for $\text{multiply}(3, 4)$.
    • Recursive GCD (Euclidean Algorithm): $$\text{gcd}(a, b) = \begin{cases} a & \text{if } b = 0 \\ \text{gcd}(b, a \pmod b) & \text{otherwise} \end{cases}$$
    • Recursive Fibonacci sequence generator ($F(n) = F(n-1) + F(n-2)$).
  • [Priority 2 - KTU Lab Program Questions] Data Processing Scripts:
    • Valid Mobile Number Validator: Check len(num) == 10, num.isdigit(), and num[0] in ['7', '8', '9'].
    • Merge Two Lists (Sorted Evens first, then Sorted Odds): Filter evens → sort; filter odds → sort; concatenate.
    • Reorganize Characters in String: Extract and concatenate: uppercase + lowercase + digits + special symbols.
    • In-place 1D Array Reversal (NumPy): Using two-pointer swap or slicing arr[::-1].
    • Right-Angled Triangle Check: Sort sides ($a, b, c$) and verify $a^2 + b^2 = c^2$.

MODULE 4: Computational Paradigms & Algorithm Design

3-Mark Questions (Part A)

  • Brute-Force Unlocking / Padlock Question:
    • A 4-digit PIN with digits 0–9 has $10^4 = 10,000$ possible combinations (from 0000 to 9999). Maximum attempts to guarantee opening = 10,000.
  • Randomized Approach Motivation:
    • Simplifies implementation, avoids worst-case inputs (e.g., randomized quicksort), provides good approximations for NP-hard/complex problems.
    • Real-world problems: Hat-check problem ($E[X] = 1$), Coupon collector problem.
  • When is Greedy Guaranteed to Give an Optimal Solution?
    • When the problem satisfies:
      1. Greedy Choice Property (a globally optimal solution can be reached by making locally optimal choices).
      2. Optimal Substructure (optimal solution to the problem contains optimal solutions to subproblems).

5 to 6-Mark Questions (Part B)

  • [Priority 1 - Sure Shot] Merge Sort (Divide and Conquer):
    • Concept: Divide array into halves until size 1, recursively sort, merge sorted halves.
    • Detailed diagrammatic split & merge tracing for given arrays.
    • Advantages (Guaranteed $O(n \log n)$, stable) & Disadvantages ($O(n)$ auxiliary space).
  • [Priority 2 - Sure Shot] Dynamic Programming (DP):
    • Memoization vs. Tabulation:
      • Memoization (Top-down): Recursion + lookup table/cache; solves only needed subproblems.
      • Tabulation (Bottom-up): Iterative table filling from base cases; no call stack overhead.
    • Climbing Stairs / Fibonacci Formulation:
      • Identify overlapping subproblems and optimal substructure ($Ways(n) = Ways(n-1) + Ways(n-2)$).
  • [Priority 3] Greedy Algorithms:
    • Task Scheduling / Max Tasks: Sort tasks by completion time in ascending order, iteratively select tasks as long as cumulative time ≤ limit.
    • Greedy Coin Change: Iteratively pick the largest coin denomination ≤ remaining amount.
    • Divide & Conquer for Two Smallest Rates: Divide list into halves, return 2 minimums from left and right, compare to find global two smallest.
